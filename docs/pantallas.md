## Flujos de comprobación

1. Publicar → Reportar → Posibles coincidencias → Es este/Lo vi o Crear ficha.
2. Grecia → Quiero ayudar → Oferta → Coordinación → Asumir tarea.
3. Grecia → Me interesa → Mensaje → Coordinación. El animal permanece en la calle.
4. Canelo → Transferencia → Aceptación como Carolina → Confirmación como Sofía → Mis mascotas.
5. Mis mascotas como Pamela → Luna → Marcar perdida → Mapa → Avistamiento → Volver como Pamela → Encontrada.
6. Chocolate como Pamela → Aceptar cuidador → Registrar novedad → Historial.
7. PetSocial → Cambiar mascota → Crear publicación con foto → Me gusta y comentario → Perfil.
